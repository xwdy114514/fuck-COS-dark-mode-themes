# 作者的要求

> 作者 = 提需求的人（本项目唯一决策者）。这一份是“产品层面想要什么”，与实现细节分开。

## 功能定位

1. **第三方主题常驻**：把 `.theme` 交给主题商店免费试用，试用到期不恢复默认。
2. **深色适配**：LSPosed 模块，把主题的插画/配色注入到不读主题资源的应用里。

## 硬性要求

| # | 要求 |
|---|---|
| 1 | 通用：ColorOS 11~17、realme UI 2.0~7.0 都能用，不绑定单一机型/版本 |
| 2 | 素材全部来自主题文件；模块不得内置主题素材；主题作者可自定义各个适配界面的素材，换图即换角色 |
| 3 | 主题锁定优先支持“只有 Shizuku、无 Root”；有 Root 也要能用 |
| 4 | 深色模式必须同时有 Root + LSPosed 才可用；不满足时该功能对用户不可见 |
| 5 | 稳定优先：不写屎山、不重复实现、不动可能导致无法开机的分区 |
| 6 | 改前查文档、改后更新文档并递增版本号 |
| 7 | 测试按“一套配色测完再换另一套”，不要频繁重启 SystemUI |
| 8 | 不催主题作者、不催更、严禁倒卖 |
| 9 | 软件内不得出现 Sui 字样（Sui 需要 root 才能刷，对用户没有区分意义），统一称 Shizuku |

## 当前已知的产品取向

- 深色适配因为问题多，曾整体下架；恢复后要求“藏起来 + 密码”双重门槛（连点版本号 7 次 + 密码）。
- 界面改版（画廊/封面那套）被否过一次，**先跑通功能再谈样式**，不要再整页换掉。
- 主题文件的命名延续 `美游艾德费尔特ColorOS17主题_dark_vN.theme` 这种“版本递增”的写法。
