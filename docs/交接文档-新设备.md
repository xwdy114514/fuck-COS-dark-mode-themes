# MCTGA 交接文档（新设备）

> 版本：`0.4`（versionCode 152） · 包名：`xwdy.deepseek.test`
> 仓库：https://github.com/xwdy114514/fuck-COS-dark-mode-themes

## 1. 这是什么

让 ColorOS 17 在深色模式下也能加载 `.theme` 主题（含 `drawable-night`），并把主题引擎不会解压的
`com.android.contacts` / `com.android.mms` 以「应用数据目录 + ContentProvider 注入」的方式补进目标进程。
**不写 `/data/theme`**，不修改任何 `.theme` 原文件。

两个部分：

| 部分 | 作用 | 依赖 |
|---|---|---|
| LSPosed 模块（Hook） | 夜间强制加载主题 zip、`drawable` 重定向到 `drawable-night-xxhdpi`、顶栏黑块清理 | LSPosed |
| 控制台（MainActivity） | 选 `.theme` 交给主题商店、补齐资源、锁定/解冻商店、诊断 | Root（补齐重启、锁定/解冻）或 Shizuku |

## 2. 环境要求

- Android 17 / ColorOS 17（`ro.build.version.oplusrom` 以 `V17` 开头，否则深色适配自动停用）
- LSPosed（Zygisk）
- Root（KernelSU / Magisk）或已启动的 Shizuku（无线调试 / ADB）
- 主题商店 `com.heytap.themestore`（不要卸载）

## 3. 安装

1. 安装 `out/MCTGA-0.4.apk`
2. LSPosed 里启用模块，作用域按 `module/res/values/arrays.xml` 勾满 **20 个包**：
   settings、systemui、contacts、mms、filemanager、alarmclock、calendar、soundrecorder、
   gallery3d、video、digitalwellbeing、familyguard、heytap.cloud、heytap.health、
   heytap.themestore、speechassist、oplus.aimemory、oplus.tips、coloros.shortcuts、android.stk
3. 打开 MCTGA，授予 Root 授权（或启动 Shizuku 并授权）

## 4. 使用流程

1. 文件管理里点 `.theme` → 免费试用（让主题商店自己应用主题）
2. 回到 MCTGA →「补齐主题资源」
   - 从 `.theme` 里按 `themeOsVersion` 选出本机变体（如 `com.android.contacts_004`）
   - 变体缺 `-night` 时，从同名基础包补同名夜间图
   - 写到 `/data/data/xwdy.deepseek.test/files/theme-packs/<包名>`
   - 有 Root 时自动重启联系人 / 短信；没有就手动结束这两个应用
3. 深色适配开关默认开启；改开关后需要让目标应用重启一次
4. 换主题：先在 MCTGA「解锁」→ 商店重新应用 → 再「补齐主题资源」

## 5. 关键实现位置

| 功能 | 代码 |
|---|---|
| 夜间强制加载 + 变体判定 | `Hook.java` → `getThemeResources` afterHook、`packBaseDir`、`zipHasNight` |
| drawable → night 重定向 | `Hook.java` → `rewriteZip` |
| 顶栏黑块 | `Hook.java` → `isBarId` / `clearBarViews` / `setBackground*` 拦截 |
| Provider | `PackProvider.java`，authority `xwdy.deepseek.test.packs`，仅允许 contacts/mms/settings/systemui/本应用 |
| 补齐 | `MainActivity.java` → `buildPacks()`（变体 + 夜间图合并、ZipFile 校验） |
| 交给主题商店 | `openThemePreview()`（`com.oplus.themestore.action.PREVIEW_THEME` + `oplus/oppo_preview_theme_path`） |
| 锁定 / 解冻 | `ThemeEngine.java`（双身份 suspend 清理、`.Themes.lockdir-*`） |

## 6. 构建

```sh
export TOOLCHAIN_PREFIX=/path/to/toolchain   # bin/aapt2、share/java/d8.jar、apksigner.jar、JDK
export ANDROID_JAR=/path/to/android-35/android.jar
export XPOSED_API=$PWD/tools/XposedBridgeAPI-82.jar
export KEYSTORE=$PWD/tools/eta.keystore       # 必须沿用，否则无法覆盖安装
sh build.sh
```

产物：`out/MCTGA-0.4.apk`。`install.sh` 会先复制到 `/data/local/tmp` 再 `pm install -r -t`。

## 7. 排错

| 现象 | 处理 |
|---|---|
| 补齐报 `EACCES ... theme-packs` | `files/theme-packs` 属主不是应用，`chown <uid>:<uid>` 后重试 |
| 商店详情页空白 | 133 MB 主题要 6–8 秒解析，等；仍空白说明商店不认这个路径 |
| 联系人 / 短信发亮 | 确认 `files/theme-packs` 里有对应包，目标应用已重启；看 `logcat` tag `CosNightTheme` |
| 深色开关置灰 | 非 ColorOS 17 会直接停用 |
| 锁定提示 `PLACEHOLDER_CREATE` | 已修；若仍出现，说明装的是旧版本 |
| 解冻后仍「已挂起」 | 检查 `dumpsys package com.heytap.themestore` 的 `suspendingPackage` 是否清空 |

日志：`/data/adb/lspd/log/modules_*.log`，tag `CosNightTheme`；高频日志用
`settings put global mctga_debug 1` 打开。

## 8. 红线

1. **不写 `/data/theme`**、不修改用户的 `.theme`
2. 不卸载主题商店（会触发恢复默认主题）
3. 不更换签名（`tools/eta.keystore`）
4. 不碰 LSPosed 守护进程（`lspctl stop` / `kill lspd` 会让框架失效）
5. 重启设备前先问用户
