| 版本 | versionCode | 改动 |

| 流程约定 | — | 作者要求：**每次更新都要在 `更新总集.md` 写一条**（改了什么 / 为什么 / 影响面），并**把本次的新注意点写进 `需要避开的坑.md`**；哪怕只改文档或只递增版本号也要记 |

### 本次约定要记住的三件事

1. 总集不能只写“修了 bug”，要写清症状、根因、改法，方便以后回溯。
2. 坑要写成“现象 → 原因 → 做法”，不要只写结论。
3. 改完同步：APK、源码包、`texts-defaults.json`、`texts.json`、四份文档，一个都不能漏。
