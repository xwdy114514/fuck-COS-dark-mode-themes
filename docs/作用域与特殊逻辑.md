# 作用域与各包特殊逻辑

## 作用域（20 个，`res/values/arrays.xml`）

| 包 | 特殊逻辑 |
|---|---|
| com.android.settings | 首页 appbar 清背景；`OplusSettingsHomepageActivity` onCreate/onResume 清背景 |
| com.android.systemui | UI 模式切换重启 SystemUI；day color scrim/blur id 缓存 |
| com.android.contacts | 主题有 OS 变体（`_004`），夜间图需按同名单图合并进变体包 |
| com.android.mms | 同上（变体 `_007`） |
| com.coloros.filemanager / alarmclock / calendar / soundrecorder / gallery3d / video / digitalwellbeing / familyguard / shortcuts | 注入插画背景（HOOK_BG）；顶栏背景清空；alarm 页特殊修复 |
| com.heytap.cloud / health / speechassist | 注入插画背景；`COUIAppBarLayout`(id `abl`) 需清背景 |
| com.oplus.aimemory / tips | 注入插画背景 |
| com.heytap.themestore | 主题商店自身，避免误清 |
| com.android.stk | 仅作用域，无特殊逻辑 |

## 资源侧要点

- 夜间判断：`Configuration.uiMode & 0x30 == 0x20`。
- 强制加载主题 zip 前先 `zipHasNight()`：主题包没有 `-night` 条目就跳过，交给系统深色。
- 顶栏清理：`isBarId()` 匹配 `appbar/toolbar/header/statusbar/abl/app_bar/action_bar/title_bar`，
  同时拦截 `setBackground`、`setBackgroundDrawable`、`setBackgroundResource`，防止被重复设回。
- 插画：`bg_day.png` / `bg_night.png` 打包在 APK 根目录，`loadBg()` 用 classloader 读。
