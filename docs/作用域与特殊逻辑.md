# 作用域与各包特殊逻辑

## 作用域（`res/values/arrays.xml`，数量以实际为准，此处不写死）

> **数量口径（2026-11-21 实机核对）**：源码 `module/res/values/arrays.xml` 声明 **22 个**；一加8T 上 LSPosed 实际勾选 **24 个**——比源码多 `com.android.cellbroadcastreceiver.module`、`com.heytap.market` 两个。源码声明的 22 个全部在实机勾选内，无遗漏。作用域数量会随源码版本与用户手动勾选变动，**不要在本文件写死数字**；需要精确数量时查源码 arrays.xml 或 LSPosed 的 `modules_config.db`。

## 资源侧要点

- 夜间判断：`Configuration.uiMode & 0x30 == 0x20`。
- 强制加载主题 zip 前先 `zipHasNight()`：主题包没有 `-night` 条目就跳过，交给系统深色。
- 顶栏清理：`isBarId()` 匹配 `appbar/toolbar/header/statusbar/abl/app_bar/action_bar/title_bar`，
  同时拦截 `setBackground`、`setBackgroundDrawable`、`setBackgroundResource`，防止被重复设回。
- 插画素材**一律从主题包读取**，模块本身不得内置任何主题素材（APK 里只有应用图标）；`loadBg()` 读取的是主题提供的背景资源，不是 APK 自带图片。
