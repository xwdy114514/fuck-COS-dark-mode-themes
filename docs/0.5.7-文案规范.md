# MCTGA 0.5.7 文案规范与覆盖迁移

## 本轮范围

主应用的状态卡、三步引导、常驻说明、手动操作、深色适配、权限授权、异常提示、诊断与关于页。修改 MainActivity、EnvCheck、ShizukuBridge 的 152 种字符串、154 处出现；布局和非字符串代码保持一致。主题锁定、Hook、AppliedTheme、ShellRunner、Texts、云控逻辑不变。编辑器应用不改版。

## 术语与承诺

- 选择文件：只选取/准备主题副本，不等于安装或应用。
- 应用主题：由主题商店完成，按钮为「免费试用」或「应用」。MCTGA 的人工确认仅记录用户确认，不冒充自动验证。
- 锁定主题 / 解锁主题：处理主题目录及商店状态，不等于切换主题。
- 冻结商店 / 解冻商店：统一面向用户用语，技术日志允许保留 suspended 等真实字段。
- 补齐主题资源：准备模块可用资源，不等于应用主题；不写 /data/theme、不修改源 .theme。
- 无有效主题：模块保留原生界面；磁盘缓存存在不能证明主题已应用或已生效。
- 权限：Root、Shizuku、LSPosed 各有作用。不能再说「与 Root 无关」「有 Shizuku 就保证读目录」。读不到与未应用必须区分。
- 成功：只陈述已有证据。刷新提交只提示正在刷新；批量停止命令完成不称所有界面已经重启或生效；锁定效果不承诺跨 ROM 永久有效。
- SystemUI 操作在按钮文案中明确命名；自动重启按钮提示可能黑屏，不再在帮助中要求每次无脑一键生效。

## 长文案和动态内容

改动逐个字符串字面量进行，并保持拼接表达式不变。动态文件名、错误、版本和数量仍由业务代码提供，不能写死。

`tools/CopyCatalog.java` 从 UI 调用/引导返回值提取完整静态文案，生成 163 项 `texts-defaults.json`。动态拼接不能自动当成整句；只为已支持的数字项补 `%n` 模板。默认表不是所有可能错误消息的穷举，不应声称包含任意文件名/异常组合。唯一保留的长片段为用户原来隐藏补齐提示的兼容用途，其余不收集源码散片或 shell 命令。

## 旧 texts.json 迁移

原文件在本机 `/data/local/tmp/mctga-copy-057/texts-original.json` 备份，工作树备份亦保留。此次用户明确要求整理软件文案，迁移如下：

- 「更多选项」「补齐主题资源」、冻结商店和主用户警告已经纳入默认文案，无须重复覆盖。
- 移除「点击直接安装」「恭喜已成功安装」等错误承诺，改为前往商店应用、引导已完成。
- 完成态更换主题说明已写入默认文案。
- 保留用户隐藏完成态补齐提示的意图，用新的精确长片段覆盖为句号；不隐藏按钮、警告或权限条件。

新 texts.json 仅 1 个有实际效果的覆盖项。不读取/改写用户私有 SharedPreferences 中已有历史操作记录，旧历史日志可能仍显示旧词句，属于历史而非新 UI 漏改。

## 注意事项

仅更改文案不能解决业务状态模型本身的局限。例如 EnvCheck 的目录项数不能称为主题包数，夜间资源抽样失败不能断言不存在主题；本轮将这些状态写成准确、有限的观察，不暗中修改探测流程。

编译/回归与真机覆盖范围见 `0.5.7-测试记录.md`。所有文件访问权限保持原状态，文案表迁移不意味着自动授予权限。
